## Проект для практического подтверждения навыков
### Наименование: FinTrack Pro
**Описание:** FinTrack Pro – персональный менеджер финансов на iOS, позволяющий пользователям вести учёт доходов и расходов, создавать категории, просматривать интерактивные графики и отчёты, а также синхронизировать данные между устройствами через Firebase. Приложение работает офлайн с использованием Core Data, а при наличии сети автоматически синхронизирует изменения. UI построен полностью на SwiftUI с поддержкой Dark Mode и локализации (RU/EN). Реактивные потоки данных реализованы через Combine, а зависимости управляются Swift Package Manager. Для обеспечения качества кода настроен CI/CD pipeline (GitHub Actions + Fastlane) с автоматическим билдом, тестированием (XCTest, Quick/Nimble) и деплоем в TestFlight. Проект ведётся по Agile‑методологии: планирование спринтов, ежедневные стендапы, ретроспективы, code review.

**Применяемые технологии:** Swift (современный, concurrency, protocol‑oriented), SwiftUI (комплексные UI, анимации, адаптивный дизайн), Combine (реактивная архитектура, управление состоянием), Core Data (локальное хранение, миграции), Firebase (Auth, Firestore, Cloud Messaging), Networking (Alamofire, URLSession), Swift Package Manager (модульность, публикация пакетов), CI/CD (GitHub Actions, Fastlane, TestFlight), Тестирование (unit, UI, Quick/Nimble), Git (branching, pull‑request workflow, code review), Agile/Scrum (планирование, бэклог, ретроспектива), UI/UX (Apple HIG, дизайн‑системы, доступность), Командная работа и коммуникация
