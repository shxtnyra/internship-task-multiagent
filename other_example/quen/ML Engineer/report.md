## Проект для практического подтверждения навыков
### Наименование: ML-Powered News Classifier with MLOps Pipeline
**Описание:** Веб-приложение, которое автоматически классифицирует новости с разных источников по темам (политика, технологии, спорт и др.) с использованием fine-tuned модели BERT на Hugging Face. Данные забираются через Airflow-пайплайн из RSS-лент, обрабатываются в GCP Cloud Functions, модель обучается и логируется через MLflow, версионируется с помощью DVC. Модель задеплоена в Docker-контейнере на Kubernetes-кластере (GKE), доступна через FastAPI. Интерфейс — на Streamlit. Реализован CI/CD через GitHub Actions: тесты, линтеры, деплой. Проект задокументирован: README, архитектурная схема, инструкции по запуску.

**Применяемые технологии:** Работа с PyTorch и Hugging Face Transformers, Fine-tuning NLP-моделей, Использование MLOps-инструментов: MLflow, Airflow, DVC, Работа с облаком: GCP, Kubernetes, Docker, Построение CI/CD для ML-проектов, Работа с SQL и API, Навыки документирования и презентации проекта
