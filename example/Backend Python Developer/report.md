## Проект для практического подтверждения навыков
### Наименование: Платформа для онлайн-обучения
**Описание:** Разработка веб-приложения, которое позволит пользователям создавать и проходить онлайн-курсы. Платформа будет включать следующие функции: регистрация и аутентификация пользователей, создание и редактирование курсов, просмотр и прохождение уроков, отслеживание прогресса обучения, система оценок и отзывов. Для развёртывания приложения будет использоваться Kubernetes, а для хранения данных — PostgreSQL. CI/CD будет настроен с использованием GitLab CI. Приложение будет развёрнуто в облаке AWS/GCP/Azure.

**Применяемые технологии:** Разработка веб-приложений на Python с использованием Django/Flask/FastAPI, Работа с базами данных PostgreSQL, Использование Docker и Kubernetes для развёртывания приложений, Настройка CI/CD с помощью GitLab CI, Работа с облачными платформами AWS/GCP/Azure, Проектирование и реализация пользовательских интерфейсов, Разработка системы аутентификации и авторизации
